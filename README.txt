NISHA PAL - PORTFOLIO

A responsive portfolio for WordPress, Elementor, WooCommerce, theme/plugin customization, API/payment integrations and selected client projects.

FILES
- index.html: portfolio page
- css/styles.css: design system, responsive rules, mobile off-canvas navigation and cursor-follow glow
- js/scripts.js: mobile navigation, reveal animation, cursor-follow effect and clickable project cards
- assets/Nisha-Pal-Resume.pdf: final clean, blackish-purple downloadable resume
- assets/Nisha-Pal-Resume.docx: editable final resume copy
- vercel.json: standard security headers

DEPLOY
Deploy the contents of this folder to Vercel. No visitor email collection, visitor tracking, page-view counters or visitor-log APIs are included.

PROJECT LINKS
Project cards open their configured destination when clicked. GymSmart currently links to https://gymsmart.com/ as requested. Aeon opens an email draft to request project details because no public project URL was provided.
